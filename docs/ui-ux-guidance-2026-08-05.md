## P1 — 规划面板重组(信息架构)

现状:单面板塞 搜索/导入/吸附行/时间轴/摘要卡/详情/10 按钮,长滚动+拥挤+网格错位。

1. **按钮分区**(10 个混排 → 3 组):
   - 编辑组:撤销/重做/清空/反向/闭环(图标化小按钮条)
   - 数据组:保存(主,橙)/分享链接/高德链接/导出GPX/导入GPX(收进「导出 ▸」折叠或移分享 tab——分享 tab 已有同构出口,规划面板只留 保存+撤销重做,其余迁出)
2. **面板分节**:「线路」(名称+时间轴)/「统计」(摘要卡+详情)/「操作」三段带分隔标题;详情 ▾ 改按钮化(边框+底色,可点击感)
3. 摘要卡大号时长语义:加小字标签「总时长」,避免「9m」裸奔
4. 底部灰色长条(疑似滚动条)改标准样式或移除

## P2 — 视觉系统统一

1. **浮层语言统一**:全部浮层(天气/日照/小地图/剖面/遥测)统一 `background: rgba(255,255,255,0.92) + backdrop-filter: blur(6px) + 1px 细边` + 2px 圆角;telemetry 加同色底框
2. **快捷钮激活态**:按下态橙底白图(现 initial 态有但切换后无视觉反馈——检查 createLayerButtons active class 切换);钮体加 0 1px 4px 微阴影在白地形上可辨
3. **橙色配额**:accent 只留给 主 CTA(保存/查询/下载)+ 路线 + 关键警示;遥测/次要文本去橙
4. 标题层级:面板 h2 线路名加大(当前比坐标还小)

## P3 — 交互反馈

1. 途经点标记 hover 显示 `cursor:grab`,拖拽中 `grabbing`(canvas cursor 切换)
2. 行间 ⊕ 常驻低可见(40% 透明)而非纯 hover 才现
3. 快捷键帮助:rail 底部加「?」浮层列 ESC/Ctrl+Z/Y
4. Toast 堆叠上限 2 条,旧的淡出
