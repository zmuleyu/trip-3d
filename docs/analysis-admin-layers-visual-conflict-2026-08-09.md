# 分析:行政区划图层 + 界面视觉降噪(2026-08-09)

基于生产截图(trip-3d.pages.dev,俯视 EL=90°)与现有架构(terrain.js shader draping / hud3d 标签 / R7 瓦片叠加 / overviewMap 瓦片)。

---

## A. 行政区划图层

### 数据源选型

| 源 | 覆盖 | 格式 | 许可 | 评估 |
|---|---|---|---|---|
| **阿里云 DataV** `geo.datav.aliyun.com/areas_v3/bound/{adcode}_full.json` | 中国省/市/县三级 | GeoJSON(含 adcode) | 公开免费使用 | **中国场景最优**:边界精确到县,按需单文件加载(省 ~100-500KB) |
| **Natural Earth** admin_1 states | 全球省级 | Shapefile/GeoJSON | Public Domain | 世界区兜底,省级够用,县级无 |
| **geoBoundaries** | 全球多级 | GeoJSON | CC-BY 4.0 | 全球县级候选,文件大,需拓扑简化 |
| OSM 瓦片自带边界渲染 | 全球 | 栅格 | ODbL | R7 叠加已隐含,低 zoom 可见但不清晰,不可控 |

**建议:DataV(中国)+ Natural Earth(境外)双源;不出矢量 tile 基础设施。**

### 渲染集成(复用既有三件)

1. **边界线**:GeoJSON → 视口 bbox 过滤 → `terrain.sample` 采高 → `THREE.Line` 贴地 draping(与路线同手法)。虚线样式区分等级:省(实线粗)/市(细)/县(虚线淡)。
2. **区划名标签**:复用 hud3d sprite 标签系统,省名在低 zoom(zoom≤9)、县名高 zoom(zoom≥12)显示——与 POI 标签共享密度规则。
3. **开关**:右侧快捷钮列加「🏛 区划边界」(与 🛣 路网叠加同族),设置抽屉加等级选择(省/市/县)。

### 加载策略
- 按当前 DEM 中心 adcode 反查(Nominatim reverse 一次,或 DataV adcode 索引)→ 只载当前省 `_full.json`(含市县) → IndexedDB 缓存(线路库同套 store)。
- 切换 DEM 位置时随 `demKey` 代际重载(与 snap/weather 同契约)。
- 境外 DEM → Natural Earth 单文件(~2MB 全球省级,一次缓存)。

### 工作量评估
边界 draping + 标签 + 开关 + 缓存 ≈ 一个 goal(L1)。数据源调研(DN/NE 文件格式细节)前置半天。

## B. 界面视觉冲突降噪

### 冲突清单(截图实证)

| # | 冲突 | 现状 |
|---|---|---|
| B1 | **规划面板盖住左上~1/4 地图**(460px 高,俯视时遮挡区更大) | 面板常驻,无折叠 |
| B2 | **底部剖面卡超出视口被裁**(截图底部卡片一半在屏外) | 贴底定位在矮视口溢出 |
| B3 | **等高线数字标签(4901/4911…)与路线/路网/POI 同灰度竞争** | 全部单色同层级 |
| B4 | **浮层五个同屏**(面板+遥测+剖面+小地图+快捷钮列),视觉重心分散 | 无焦点模式 |
| B5 | 遥测面板在规划时无信息量(CAM/FPS 对规划用户无意义) | 常驻 |

### 降噪策略(按收益排序)

1. **面板折叠态(B1)**:头部常驻(线路名+统计一行+展开钮),详情收起;打点模式自动展开,退出规划自动收起。收益最大。
2. **焦点/巡演模式(B4)**:tour 巡航/飞越录制时自动隐藏所有浮层(面板/遥测/剖面/小地图),结束恢复;录视频画质直接受益。
3. **标签密度规则(B3)**:等高线高程标每隔 N 条显示;POI 标签 zoom≥11 才出;路线存在时等高线标签透明度减半——路线永远视觉主导。
4. **剖面卡定位修正(B2)**:max-height + 贴底 clamp,矮视口不溢出。
5. **遥测按需(B5)**:规划/分享 tab 激活时自动隐藏(它是开发向信息)。

### 建议波次
- **UX3 降噪**:B1+B4+B3+B2+B5(纯前端,~一个 goal)
- **L1 行政区划**:数据源调研 + 边界 draping + 标签 + 开关(一个 goal,前置调研)

两波独立,可先 UX3 后 L1。
