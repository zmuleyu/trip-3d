# GOAL — 2D 精确规划 + 3D 地形预览高保真 Mockup

## 目标

把已确认的推荐方向 B 转化为可点击、高保真的交互 mockup；本 Goal 只做设计拍板材料，不修改生产 UI。

## 验收标准

- 桌面主态：2D 精确规划为 Operate 主工作区，3D 预览保持产品差异化。
- 桌面路线态：起终点、途经点、交通模式、路线统计、高程分析与图层层级清楚。
- 超覆盖态：路线超出 DEM 时停止伪精确高程统计，给出可恢复动作。
- 移动态：bottom sheet，不与图层、剖面和地图重叠；主要触控目标至少 44px。
- 支持键盘切态与 Escape；非必要动效尊重 prefers-reduced-motion。
- HTML 可直接打开，浏览器控制台 0 JS 错误。

## 非目标

- 不修改 src/ 生产实现。
- 不重构路线数据模型或 DEM 加载。
- 不部署、不 commit、不 push。
