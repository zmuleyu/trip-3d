# GOAL — trip-3d UI 交互改造(地图产品化)

## 最终目标
将 trip-3d 的 UI 从 lil-gui 实验台形态改造为地图产品形态,按已确认的预览稿(dist/ui-mockup.html)实施:
- 左侧 52px 图标轨道:🗺规划 / 📁线路库 / 🌦天气(P2 占位禁用) / ↗分享(P3 占位禁用) / ⚙设置(底部)
- 飞出式上下文面板(规划面板:线路名+途经点列表+统计卡+操作按钮;线路库面板:列表+加载+删除)
- 右上高频图层圆钮:等高线/测量网格/山峰标签/HUD
- monolith 全部 lil-gui 渲染参数降级进「设置」抽屉,默认收起
- 底部高程剖面浮卡(≥2 点出现,可折叠),复用现有剖面绘制
- 模式状态机 browse|planning 驱动打点监听;ESC 退出规划态;保存/分享成功 toast

## 验收标准
1. `npm test` 全绿(现有 32 + 新增 mode 测试)
2. `npm run build` exit 0
3. E2E(远程浏览器):轨道/面板/剖面卡渲染;规划态点击落点正常;ESC 退出;设置抽屉内含 lil-gui;图层钮切换生效;保存→toast+线路库出现;视觉截图确认
4. 现有功能无回归(打点/连线/统计/剖面/保存/加载/删除/分享复原/GPX)

## 非目标
- 天气/分享 tab 的实际功能(P2/P3,仅轨道占位)
- lil-gui 原生化重写(本期整体搬迁,不改其内部)
- 移动端布局(仅预留)
- 拖拽改线、undo/redo 栈(followups 已有)
