# GOAL — trip-3d 搜索驱动打点 + 路网吸附 + 多点天气(双轨:高德占位)

## 最终目标
1. **地点搜索**:规划面板顶部搜索框(Nominatim 主 / Photon 备),防抖+1req/s 合规;结果点击=飞达+加载 DEM;每条结果带 ⊕ 加为途经点
2. **路网吸附**:OsrmProvider(foot profile);规划面板「路网吸附」开关;ON 时相邻途经点间用 OSRM 几何;分段缓存+失败降级直线;统计/剖面用真实几何
3. **多点天气**:天气面板加「全部途经点」开关,默认代表点(3 请求),展开后逐途经点(≤32)
4. **高德占位**:geocode/routing KINDS 注册 'amap' stub,调用即抛「占位未实现」;GCJ-02 转换层不进本期

## 验收标准
1. `npm test` 全绿(71 既有 + geocode/osrm/polyline 新增)
2. `npm run build` exit 0
3. E2E:搜索「四姑娘山」出结果→⊕加途经点→吸附开关 ON→OSRM 真实几何渲染(线段顶点数远大于样条)/统计为真实里程;多点天气展开出卡;无回归
4. 分享 hash 不含吸附几何(重算),体积不膨胀

## 非目标(红线)
- 高德实体实现(key/GCJ-02/条款评估)——本期仅 stub 占位
- 实时导航、多交通方式、自托管 OSRM
- 吸附几何持久化(IndexedDB/hash 均不存)

## 已确认决策
- 双轨:OSM 系主干(免 key/WGS-84 零转换/条款干净);高德仅接口占位
- 吸附几何不进分享 hash,打开时重算
- 多点天气:代表点默认 + 全途经点按需展开
